Perguntas

O que é esta página?

Um teste local de movimento, tipografia e cor.

A Tramo existe?

Não. O nome e a forma da logo são fictícios.

De onde vêm as imagens?

São desenhadas por código no navegador. Nada foi baixado.

Os clientes são reais?

Não. Estúdios, nomes e histórias desta página são inventados.

O formulário envia algo?

Não. Ele só avisa que nada foi enviado.

Dá para reduzir o movimento?

Sim. A preferência de movimento reduzido do sistema é respeitada.

Funciona sem placa de vídeo?

Sim. Sem WebGL, o hero mostra uma composição parada.

Tem algo escondido no fim?

Sim. Continue rolando quando a página acabar.
